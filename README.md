# 视频制作 OS · v1.3.13

把图片／视频创作网页、剧本、固定提示词、分集资产和人物音频整理到一个本地工作台。作者：[SJT-bright](https://github.com/SJT-bright)。应用使用 Electron、Node.js、原生 HTML/CSS/JavaScript 和 SQLite；生成仍在使用者自己的第三方网站账号中完成。

GitHub 自动生成的 Source code ZIP 是源码，不是可直接运行的 App。安装包无个人剧本、素材、数据库或网站登录配置。新用户会建立自己的工作区；升级时只替换软件，不删除用户数据目录。

## 核心工作流

### 创作浏览器

图片与视频模式各自保存网页标签、地址、名称、顺序及选中状态，同一网站共享本机登录。切回工作台、打开资产库或剧本选择器不销毁网页。“清空网页”先确认；取消不改变标签，确认后清空状态也会记住。

工具栏提供地址、前往、刷新、双拼、外部打开和文件导入。双拼同时保留两个原生网页，可以左右操作并由网站处理拖入的内容；进入另一个模式或重新启动后恢复普通单页。第三方网站的登录与内容由网站管理；Chrome 可用不代表内嵌浏览器一定通过验证。遇到网站限制可在系统浏览器继续，再导入下载的文件。

### 剧本与提示词

固定提示词、剧本分组和段落支持顶部原位改名、同排复制与删除。固定模板按剧本与图片／视频模式保存；右键剧本可主动迁移到指定剧本，方式为新增，重复内容跳过，不覆盖已有模板。

### 资产与下载

资产按剧本保存，人物、场景、物品、视频、图片、音频、BGM／音效和成片共享文件索引。可建立子文件夹、改名、移动、多选、复制复用和定位原文件；外部来源与 Obsidian 为索引，不擅自移动源文件。

下载视频先选“可剪辑”或“待处理”，再归档到相应网站和集目录。普通“浏览器下载”仅保留文档、压缩包等非媒体文件，图片、视频、音频进入各自媒体分类。浏览器下载文件的永久删除明确确认后执行，计数根据实际文件刷新；其他资产删除保留系统可恢复处理，不混同两种操作。

```text
创作资产库/自己的剧本/
├── 生成视频/核绘/
│   ├── 第1集/可剪辑/
│   ├── 第1集/待处理/
│   └── 第2集/…
├── 生成图片/GPT/第1集/
├── 音频/
└── 浏览器下载/
```

### 人物音频

从视频提取原混合音轨，查看波形、试听、循环播放，默认截取 2.1 秒，也可自由调整。命名并保存到本剧音频分类或另存为。输出 WAV、PCM 16 bit、24 kHz、单声道；不会自动分离说话人、BGM 或音效。

### 原文件拖出

视频卡片右键打开独立置顶浮窗，可预览并拖出原文件，拖动开始后收起浮窗；关闭只收起，不移动或删除素材。向剪映／Updream 等软件的实际接收结果取决于目标应用，自动测试的拖拽回执不代表外部导入已经完成。

## 数据与升级

公开下载版将个人工作区放在 Electron 用户配置目录，不写在 App 包内。

- macOS：`~/Library/Application Support/视频制作 OS/workspace/`
- Windows：`%APPDATA%\视频制作 OS\workspace\`

网页登录与标签保存在同一用户配置根目录中。源码绑定的开发版本使用自己的项目目录；不会自动把开发数据迁入公开下载版。软件回退时只替换 App，不用旧数据库覆盖更新后创建的素材和记录。

## 从源码运行或构建

Node.js 要求至少 22.12；`.nvmrc` 固定 26.7.0，`package-lock.json` 固定依赖。请用 `npm ci`，保留锁文件和开发依赖。

```sh
mkdir video-production-workspace
cd video-production-workspace
git clone https://github.com/SJT-bright/video-production-os.git 视频制作OS
cd 视频制作OS
npm ci
npm run desktop
```

[Mac 复现及构建指南](MAC-REPRODUCE.md) · [Windows 复现及构建指南](WINDOWS-REPRODUCE.md) · [自动化接口](AUTOMATION.md)。应用是本地桌面工作台，不是 GitHub Pages 在线网站，不内置生成模型、账号或付费额度。

## 验证边界

发布工作流在实际 Mac／Windows runner 中检查共享源码、正文分集、真实打包启动、独立用户数据、标签留存／清空确认、图片改名、双拼布局与侧栏状态以及内置音轨截取；通过后才上传 Release。Mac universal 包包含两个架构，启动证明只覆盖 runner 实际执行的架构，不冒充 Intel 实机验收。双拼布局验证不等同于物理鼠标跨网页拖拽验收；第三方网站的真实上传、生成与外部软件收件仍需在使用者设备确认。
